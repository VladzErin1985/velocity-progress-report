✅ Technical Discoveries This Week

Native n8n Anthropic node has a credential bug — switched to HTTP Request node for all Claude calls (working perfectly)
GHL V1 API was deprecated Dec 31 2025 — all calls now use V2 (services.leadconnectorhq.com) with PIT token authentication
GHL requires locationId in every V2 API body or returns 403 — added to all nodes
GHL Conversations API requires "html" field for email body (not "body" or "message") — fixed in WF-VC-02
GHL auto-enables DND on contacts with repeated email bounces — must manually disable per contact in GHL settings
n8n "Using Fields Below" mode prevents Claude's special characters from breaking JSON — applied to all Claude output nodes
GHL V2 /contacts/ search by email returns 422 — redesigned WF-VC-03 to pass contactId directly in webhook payload (more reliable)
