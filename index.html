Technical Discoveries (All Sessions)

Native n8n Anthropic node has a credential bug — switched to HTTP Request node for all Claude calls
GHL V1 API deprecated Dec 31 2025 — all calls use V2 (services.leadconnectorhq.com) with PIT token
GHL requires locationId in every V2 API body or returns 403
GHL Conversations API requires "html" field for email body — not "body" or "message"
n8n "Using Fields Below" mode prevents Claude special characters from breaking JSON
GHL V2 /contacts/ search by email returns 422 — pass contactId directly in webhook payload instead
WF-VC-05: IF node requires conditions.options.version = 2 — missing causes silent validation failure
Claude API response is at content[0].text — access via $input.item.json.content[0].text
Plain text with \n renders as wall in Gmail — split on \n\n, wrap in <p>, replace inner \n with <br>
[May 8] Pipedrive Webhook requires Growth plan — n8n polls Pipedrive API for triggers instead.
[May 8] Pipedrive Deal Labels NOT created in Settings → Labels. Must create from within an actual Deal record.
[May 8] All new Pipedrive automations default to Asia/Taipei timezone — change to America/Los_Angeles.
[May 25] Retell publish requires separate POST /publish-agent-version/{id} with {"version": N} — is_published: true in PATCH body does NOT publish.
[May 25] Retell Voice Orb token is version-specific — after publishing new version, regenerate embed URL from dashboard Share modal.
[May 25] Retell post_call_analysis_data: "enum" is NOT a valid type — use "string" + choices array. PATCH replaces full array, always send all fields.
[May 25] n8n REST API: PUT /api/v1/workflows/{id} settings must ONLY contain {executionOrder: "v1"} — extra properties cause 400.
[May 25] WordPress contact form to n8n webhook requires KONSIER_WEBHOOK_URL + KONSIER_WEBHOOK_SECRET in wp-config.php before KS-WF3 can receive submissions.
[May 25] Retell fires both real-time transcript events AND post-call call_analyzed to the same webhook URL — always filter by event type in first IF node.
