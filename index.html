✅ Technical Discoveries (All Sessions)

Native n8n Anthropic node has a credential bug — switched to HTTP Request node for all Claude calls (working perfectly)
GHL V1 API was deprecated Dec 31 2025 — all calls now use V2 (services.leadconnectorhq.com) with PIT token authentication
GHL requires locationId in every V2 API body or returns 403 — added to all nodes
GHL Conversations API requires "html" field for email body (not "body" or "message") — fixed in WF-VC-02
GHL auto-enables DND on contacts with repeated email bounces — must manually disable per contact
n8n "Using Fields Below" mode prevents Claude's special characters from breaking JSON — applied to all Claude output nodes
GHL V2 /contacts/ search by email returns 422 — redesigned WF-VC-03 to pass contactId directly in webhook payload
WF-VC-05: IF node requires conditions.options.version = 2 — missing this caused silent validation failure
GHL Opportunities API (/opportunities/search) does NOT accept pipelineId as query param — must pull all then filter in Code node
Claude API response text is at content[0].text — never $json.text. Always access via $input.item.json.content[0].text
Plain text email with \n chars renders as wall of text in Gmail — convert to HTML: split on \n\n, wrap in <p>, replace inner \n with <br>
[May 8 — Pipedrive] Pipedrive Webhook action requires Growth plan — webhook option not clickable on current plan. n8n polls Pipedrive API for triggers instead.
[May 8] Pipedrive Deal Labels are NOT created in Settings → Labels. Must create from within an actual Deal record → Add labels → + Add label button.
[May 8] All new Pipedrive automations default to Asia/Taipei timezone — must manually change to America/Los_Angeles (Pacific) for Drew's account.
[May 8] Slack private channels: Admin can /invite @bot via UI. Admin conversations.invite API scope is Enterprise Grid only — standard workspaces use UI invitation only.
[May 25 — Retell AI] Publishing a Retell agent requires separate POST /publish-agent-version/{agent_id} with body {"version": N} — setting is_published: true in PATCH /update-agent body does NOT publish.
[May 25 — Retell AI] Voice Orb embed token is version-specific — after publishing a new agent version, must regenerate fresh embed URL from dashboard Share modal (version dropdown → refresh → copy link).
[May 25 — Retell AI] post_call_analysis_data field type "enum" is NOT valid — use "string" + choices array. "system-presets" type works for built-in fields (call_summary, user_sentiment). PATCH replaces the full array — always send all fields.
[May 25 — n8n REST API] PUT /api/v1/workflows/{id} settings field must ONLY contain {executionOrder: "v1"} — any extra properties cause 400 error. Always GET first, modify nodes in memory, then PUT full object back.
[May 25 — WordPress webhook] Konsier contact form → n8n HMAC webhook requires both KONSIER_WEBHOOK_URL + KONSIER_WEBHOOK_SECRET in wp-config.php. KS-WF3 cannot receive submissions until Michael adds both values.
[May 25 — Retell AI] Retell fires both real-time transcript events AND post-call call_analyzed events to the same webhook URL. Always filter by event type in the first IF node (call_analyzed only) to avoid double-processing.
